# 理解人类 · From Neurons to Mind

一套可实际运行的中文交互式数字教材，将脑科学、心理学、认知与行为科学连接起来。适合非专业背景的研究生长期自学。

在变化迅速、竞争与压力交织的社会中，我们希望帮助更多人科学、系统地理解大脑、情绪与行为。通过课程、实验、案例和主动回忆，认识日常精神与心理困扰可能涉及的多层因素，为面对生活中的压力与困惑积累更清晰的理解和可检验的思路。

本项目是教育与自学资源，不提供个体诊断或治疗方案，互动演示不能作为临床测评。

## 直接使用

Windows 双击 **启动网站.cmd**，然后在浏览器打开 `http://127.0.0.1:4173/`。交付目录已包含生产版 `dist/`，此方式不需要安装网站依赖。启动器优先使用系统 Node.js，没有时尝试当前 Codex 内置 Node.js；换电脑需要安装 Node.js 22 或更高版本。

保持启动窗口打开。不能直接双击 `dist/index.html`：浏览器的模块和离线缓存要求 HTTP/HTTPS 服务。首次加载生产版、等待左下角“离线缓存已就绪”后，可以断网使用全部课程与实验。安装为桌面应用的入口由浏览器决定；离线缓存不依赖安装。

## 开发、安装与构建

安装 Node.js 22+（包含 npm），在本目录打开终端：

```bash
npm install
npm run dev
```

开发地址 `http://127.0.0.1:5173/`。开发模式不启用 Service Worker，避免开发缓存干扰。

```bash
npm run build
npm run preview
npm test
npm run check:content
```

构建先做 TypeScript 检查，再生成 `dist/` 与带内容哈希版本的离线缓存。生产预览默认 `http://127.0.0.1:4173/`。项目没有单独配置 lint；已提供类型、内容完整性及学习调度测试。

## 产品功能

动态效果：页面淡入、章节随滚动入场、首页分层展开与轨道慢转、按钮与卡片悬停反馈、内容平滑展开/收起、知识卡3D翻面、答题反馈出现、脑区与图谱高亮渐变、手机菜单滑入。顶部星光按钮可以开关动态效果，选择保存在当前浏览器；系统启用“减少动态效果”时自动关闭。动画均使用本地CSS和浏览器API，不新增线上依赖。

更新后保持本机服务启动，再刷新网页。如果仍显示旧版，可关闭该网站标签页后重新打开同一地址；不要清除网站数据，以免丢失本机学习记录。

- 20 个课程模块：方法论、神经硬件、结构网络、知觉注意、学习记忆、情绪、压力、奖励、自控、决策、睡眠、人格、社会、发展、心理健康、意识、自由意志、预测加工、AI 与人脑、综合解释。
- 课程包括学前预测、目标、直觉、机制、研究证据、扩展、图解、案例、回忆、小实验、知识检查、总结、卡片和引用。
- 脑区探索含16个结构与3类网络教学示意；交互神经元；26节点知识网络。
- 11 个实验或演示：Stroop、2-back、反应时、框架效应、变化盲视、奖励学习、Müller-Lyer、记忆误导、无意视盲、睡眠结构、Big Five。最后两项是观察/模型演示；所有任务都不是标准心理测评。
- 间隔复习、错题本、混合测验、案例推理、中英术语、离线导师、学习统计、成就、收藏、进度文件备份。

## 架构与知识库

React + TypeScript + Vite；Lucide 图标随构建打包；自定义 CSS 与 SVG 可视化；没有运行时 CDN、在线字体或分析追踪。

```
src/
  components/       神经网络视觉、测验控件
  pages/            首页、课程、复习、统计、案例、导师
  data/             内容、问题、卡片、引用、术语与脑结构
  hooks/            静态路由
  store/            进度持久化、日期、复习与备份校验
  utils/            后续服务端导师接口适配器
  features/
    brain/          Brain Explorer
    lab/            实验与演示
    knowledgeGraph/ 知识连接
  styles/           视觉系统、响应式
scripts/            构建缓存、静态服务、内容检查
tests/              调度、连续日期、恢复校验
deploy/             Nginx 示例
```

`src/data/core.json` 保存模块0–10；`advanced.json` 保存11–19。每个模块的 `lessons` 数组是独立内容对象，类型定义见 `src/data/types.ts`。引用保存在两个 `*-references.json`，用 `id` 关联。所有解释为原创中文摘要，原文链接作为可联网查阅的参考材料。核心功能不依赖这些链接。

### 新增课程

在对应模块 `lessons` 新增唯一 `id`，填写 `title`、`englishTitle`、`question`、`objectives`、`prediction`、`intuition`、`mechanism`、`evidence`、`extension`、`diagram`、`case`、`reflection`、`experimentHint`、`summary`、`misconceptions`、`quiz`、`cards`、`concepts` 与 `references`。

至少添加两道测验、两张卡片。引用键必须存在，运行 `npm run check:content`。新增术语可编辑 `src/data/glossary.ts`。课程中的概念标签支持悬停说明并链接到词典。

### 新增 Quiz / Flashcard

`quiz` 项格式：`{prompt, options:[四个选项], correct:从0开始的正确索引, explanation}`。`cards` 项：`{front, back, misconception}`。课程内容不硬编码在 React 组件中，综合题库与卡片库自动从数据聚合。调整题目或卡片顺序会改变相应记录索引，已有用户的稳定条目应尽量保持顺序。

## 路由与静态部署

使用 Hash 路由，地址形如 `/#/learn`、`/#/learn/4`、`/#/lesson/m4-l1`。这样 COS/OSS/Nginx 直接静态托管无需额外路由回退，刷新与断网也能保留入口。功能入口：`/`、`learn`、`map`、`brain`、`lab`、`review`、`quiz`、`flashcards`、`mistakes`、`glossary`、`progress`、`cases`、`tutor`、`about`。

国内部署步骤见 **国内部署指南.md**。上传 `dist/` 里面的文件到网站根目录，保留 `assets/`、`sw.js`、manifest与图标。若部署在子路径，`base:'./'` 与相对资源路径支持该形式；导航仍为同目录下 Hash 路由。

**PWA 需要 HTTPS 或 localhost。** `index.html` 和 `sw.js` 应使用无缓存或短缓存；带哈希的 `assets/` 可以长期缓存。更新后重新联网加载，Service Worker 安装全部新资源成功后切换版本。部署包不强绑定任何国外 SaaS。

## 学习进度与备份

数据以 `understand-human:v1` 键保存在 LocalStorage，包括完成课程、每次答题、错题、复习计划、实验记录、学习日期和时间、路径、预测与笔记、收藏。打开统计页，点击“下载进度备份”。若浏览器未开始下载，可在备用文本区复制 JSON 并保存。导入 JSON 将替换当前进度；导入前先保留自己的备份。随附的“空白学习进度.json”用于自主重置：导入会清空当前学习记录，使用前请先备份。

网站地址、端口、协议或浏览器改变时，存储空间也可能改变。例如从本机迁移国内域名后，使用导入功能恢复。清理浏览器或隐私模式不能保证长期保留。已知损坏格式会被拒绝；启动器与网站不会自动上传数据。

复习初次安排1天后；选择“基本掌握”依次进入3、7、14、30天，之后保持30天；“需要再学”回到1天。它是可解释的固定教学计划，不是个体化遗忘曲线预测。

## 科学解释与边界

每节包含研究证据与限制，意识、自由意志、预测加工等理论保留争议。脑区与功能、递质与行为不能做一一对应。心理健康内容仅教育，不能替代诊断和治疗；Big Five 条目为原创非标准化演示，不能当专业量表。个人网页实验受设备、时序、练习与样本量影响。
